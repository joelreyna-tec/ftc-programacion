# FTC Programación - Repo base

## Objetivo
Repositorio base para las prácticas de Java en Android Studio. El módulo `console` contiene todo lo necesario para correr programas de consola.

## Requisitos
- Android Studio instalado (que incluya JDK)
- GitHub Desktop (opcional) o Git CLI
- Cuenta de GitHub

## Pasos rápidos (para alumnos)
1. Clonar repo con GitHub Desktop o `git clone https://github.com/joelreyna/ftc-programacion.git`
2. Abrir Android Studio → File → Open → seleccionar la carpeta del proyecto (donde está `settings.gradle`).
3. Esperar a que Gradle sincronice.
4. Ejecutar ejemplo: `console/src/main/java/com/voltec/console/Main.java` → botón derecho → Run 'Main.main()'.
5. Crear tu paquete: `src/main/java` → New → Package → `semana1.alumnos.<tu_github_user>`
6. Dentro del paquete, New → Java Class → `Main` → pega el código y personaliza el mensaje.
7. Ejecuta tu `Main` con click derecho → Run.
8. En GitHub Desktop: Commit your changes → Push origin.
